📊 Finance Dashboard — Power BI  

🔍 A Professional Portfolio Project by Roja M    
This project showcases my ability to transform raw financial data into meaningful insights using Power BI, applying data cleaning, modeling, DAX, and visualization best practices.
The dashboard is designed to support decision-making through clear KPIs, interactive visuals, and intuitive navigation.     

📌 Project Overview    
    This interactive Finance Dashboard provides a refined view of critical financial KPIs including Revenue, Expenses, Profit, Category Insights, and Time-based performance.
Built to demonstrate analytical thinking and professional dashboard design for real-world business scenarios.    

🎯 Key Features    
  📈 KPI Cards: Revenue, Profit, Expenses     
  📊 Visuals: Column Charts, Line Charts, Donut Charts, Category Analysis        
  🧭 Page Navigation Buttons        
  🔍 Slicers for Year, Month, Category        
  🌐 Embedded External Link for additional resources        
  🧼 Clean and modern Power BI layout       
  👨‍💼 Portfolio-ready professional design     

🧰 Technologies Used    
  Power BI Desktop 
  Power Query for data shaping  
  DAX for custom measures 
  Excel/CSV as data source 
  GitHub for versioning and portfolio presentation
